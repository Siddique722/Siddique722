I am a Flutter Developer passionate about creating clean, responsive, and high-performance applications for Android, iOS, Web, and Desktop.

My primary focus is developing applications that combine beautiful user experiences with maintainable architecture and scalable backend solutions. Alongside Flutter, I work with Firebase, REST APIs, Node.js, and modern development tools to deliver complete solutions.
